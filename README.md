# AI 智能体辅助管理平台

Electron、React 和 TypeScript 实现的光储直柔监控平台。

## 智诊精巡双 AI

智诊精巡可切换「高精度智能运维系统」与「智能数据分析系统」，分别保存图片诊断和资料分析会话。智能数据分析系统接受任意格式文件，空文件和大文件也可触发回复，按上传时右上角 PLC 同步时钟的月份回复固定建议：12/1/2 月为冬季 42～48 度，3～5/9～11 月为春秋季 30～38 度，6～8 月为夏季 20～25 度。选择文件即触发固定回复，仅保存文件名、大小及月份，不读取或解析文件内容，也不存储原始文件；回复卡片不显示月份依据。

上传后生成待审核工单，用户可在回复卡片点击「下发工单」，也可进入工单中心审核下达。下达后 C 平台才收到个人任务，沿用 A 监护、B 隔离验电、C 调整及回填、B 恢复、A 完成监护的流程；倾角回填包含实际角度、支架紧固及复测确认。历史建议和工单保留上传时的月份，切换月份后再次上传可生成新工单。

运行 `npm run test:tilt` 验证月份对应、旧数据库兼容、聊天切换、任意格式文件及空文件、大文件上传、失败重试、人工下发、C 平台接收与回填。测试使用临时数据库和隐藏 Electron 窗口，不连接现场设备。开发命令 `npm run dev` 已启用后端及预加载代码监听，修改后自动重启 Electron，避免页面更新而工单服务仍使用旧校验规则。

## PLC Modbus TCP

应用默认通过 Modbus TCP 连接 `192.168.0.1:503`，每秒使用功能码 `03` 一次读取零基 Holding Register `HR200–HR303`。PLC 标签中的 M 区字节地址按“字节地址 ÷ 2”换算为寄存器地址。四路光伏电压、电流按大端无符号 16 位 `WORD` 读取，原始值除以 `1000` 后供平台显示和计算；蓄电池仍使用大端 IEEE-754 `REAL`。同一寄存器内，偶数 M 字节地址映射高字节，奇数 M 字节地址映射低字节。

| PLC 标签          | PLC 地址 |  Modbus 地址 | 类型       |
| ----------------- | -------- | -----------: | ---------- |
| 四路光伏组串电压1 | `%MW400` |        HR200 | WORD ÷1000 |
| 四路光伏组串电流1 | `%MW402` |        HR201 | WORD ÷1000 |
| 四路光伏组串电压2 | `%MW404` |        HR202 | WORD ÷1000 |
| 四路光伏组串电流2 | `%MW406` |        HR203 | WORD ÷1000 |
| 四路光伏组串电压3 | `%MW408` |        HR204 | WORD ÷1000 |
| 四路光伏组串电流3 | `%MW410` |        HR205 | WORD ÷1000 |
| 四路光伏组串电压4 | `%MW412` |        HR206 | WORD ÷1000 |
| 四路光伏组串电流4 | `%MW414` |        HR207 | WORD ÷1000 |
| 蓄电池组电压      | `%MD500` |    HR250–251 | REAL       |
| 蓄电池组电流      | `%MD504` |    HR252–253 | REAL       |
| Plc_Year          | `%MW600` |        HR300 | UInt       |
| Plc_Mon           | `%MB602` | HR301 高字节 | USInt      |
| Plc_Day           | `%MB603` | HR301 低字节 | USInt      |
| Plc_Hour          | `%MB604` | HR302 高字节 | USInt      |
| Plc_Min           | `%MB605` | HR302 低字节 | USInt      |
| Plc_Sec           | `%MB606` | HR303 高字节 | USInt      |
| Plc_weekday       | `%MB607` | HR303 低字节 | USInt      |

可通过环境变量覆盖连接参数：

```bash
PLC_HOST=192.168.0.1 \
PLC_PORT=503 \
PLC_UNIT_ID=1 \
PLC_POLL_INTERVAL_MS=1000 \
npm run dev
```

如需脱离 PLC 使用模拟数据，可设置 `PLC_MODE=simulation`。模拟模式下的光伏 1–4 电压/电流依次为 `210 V / 19 A`、`210 V / 19 A`、`222 V / 21 A`、`220 V / 20 A`，蓄电池为 `52 V / 5 A`；PLC 时钟从 `2026-09-01 15:30:30` 开始按采样周期递增。

## PLC 点位调试网页

启动平台后，打开 `http://127.0.0.1:17880/plc`，或从管理端「设置中心 → PLC 点位调试」进入。同一局域网的电脑、手机可通过 `http://运行平台电脑的Wi-Fi地址:17880/plc` 访问；页面顶部提供当前局域网链接。运行平台的电脑需要能连接 PLC。这里提供的是局域网访问地址，公网访问需要另行配置网络入口。

1. 填写真实 PLC 的 IP、TCP 端口、Unit ID，以及寄存器偏移（默认 `0`，地址使用零基 HR），点击「连接并读取」。初始参数来自平台的 `PLC_HOST`、`PLC_PORT`、`PLC_UNIT_ID`、`PLC_REGISTER_OFFSET`；读取成功后在当前浏览器记住连接参数。
2. 编辑四路光伏、蓄电池的电压或电流，点击该行「写入」，或勾选多行后点击「写入已选点位」。光伏点位输入换算后的 V/A 数值（`0–65.535`，最多 3 位小数），写入时自动乘以 `1000`，例如 `12.345` 写入原始值 `12345`。空值和无效数值不会提交，未勾选的点位不会写入。
3. PLC 时钟的年、月、日、时、分、秒、星期整组提交。可先「填入本机时间」，再「写入 PLC 时钟」。星期采用现有映射：`1=周日`、`7=周六`；写入这些 M 区点位不等于修改 PLC CPU 的系统时钟。
4. 查看逐项写入结果，包括提交值和回读值。批量写入逐项执行，不是整个批次的原子事务；遇到拒绝、回读不一致、连接中断或超时，就停止后续点位。状态未确认时应先重新读取，不会自动重试写入。

读写通过平台后端完成：功能码 `03` 读取，功能码 `16 / 0x10` 写保持寄存器。每个光伏 WORD 只写一个寄存器，避免覆盖相邻点位；每个蓄电池 REAL 的两个寄存器一次写入，时钟的四个寄存器一次写入，并保持既有大端字节序；每次写入应答后立即回读比较。协议参考 [Modbus 官方规范](https://www.modbus.org/file/secure/modbusprotocolspecification.pdf)。PLC 需要开放相应寄存器及写入功能；如果梯形图/PLC 程序在每个扫描周期刷新这些 M 区变量，手动写入的值可能很快被覆盖，页面会报告回读不一致。

调试目标独立于主监控采集配置，修改调试页面 IP 不会切换监控采集目标。主监控连接同一台 PLC 时，会在后续采样中显示实际读数。调试接口即使在平台模拟模式下也操作指定的真实设备。写入请求与结果记录在本地事件日志中。

验证读写实现（仅连接本机临时 Modbus 服务，不操作真实设备）：

```bash
npm run test:plc
```

## Pad 局域网访问地址

### 全平台语音

设备运行告警、AI 诊断结果、工单自动关闭提醒和 Pad 员工任务都通过管理端 `/api/speech` 生成语音，桌面与安卓使用相同的 Qwen3-TTS 服务和音色。全平台统一遵循「设置中心 → 语音播报」的配置；选择「阿里云优先，离线备用」后，正常播报均由 Qwen3-TTS-Flash 合成，云端异常时自动使用内置离线引擎。

每次打开员工任务页，点击「开启语音播报」或「点击恢复播报」。所有设备都通过普通音频播放器播放平台生成的 WAV，不调用系统文字转语音。浏览器拦截自动播放时，告警、AI 诊断和工单提醒会显示「点击播放」，保留已生成音频供点击恢复。不同页面组件共用同一播报通道，新播报会停止上一段；关闭弹窗、清空对话或离开页面会取消相关请求与音频。

平台默认使用管理端电脑内置的 **sherpa-onnx 1.13.7 + AISHELL3 轻量中文模型**生成音频（固定音色 sid=10、8 kHz 单声道 WAV），也可在管理端「设置中心 → 语音播报」启用 **阿里云百炼 Qwen3-TTS-Flash**。安卓端无需安装引擎或中文语音包，通过局域网连接正在运行的管理端即可。离线模式无需互联网，轻量模型适合中文工单提示，音质和英文混读能力有限。

云端配置：选择「阿里云优先，离线备用」，填写与百炼密钥一致的地域、系统音色（默认 `Cherry`）及 API Key，保存后点击「测试云端并试听」。新版业务空间密钥还需要填写创建页面提供的 **API Host**，例如 `ws-业务空间ID.cn-beijing.maas.aliyuncs.com`（只填域名，不含协议或路径）；旧版密钥可留空，使用该地域的 DashScope 地址。北京与新加坡的密钥不能混用。账号须有模型调用权限、可用额度或余额，管理端须可访问相应阿里云接口和 OSS 音频地址。详见[百炼密钥说明](https://help.aliyun.com/zh/model-studio/get-api-key)和[Qwen-TTS API](https://help.aliyun.com/zh/model-studio/qwen-tts-api)。

密钥仅通过管理端桌面 IPC 设置，由系统 `safeStorage` 加密存入用户数据目录的 `speech-settings.json`，不返回给网页、不发送到 Pad、不放入安装包。留空保存保持原密钥；清除密钥会切回离线模式。也支持管理端进程的 `DASHSCOPE_API_KEY` 环境变量。加密配置不能直接跨电脑迁移，其他电脑需在设置页重新填写密钥。云端模式会将播报文字发送到阿里云；45 秒超时或任一分段失败时，整条内容改用离线合成，并暂缓云端重试 30 秒。「测试云端」仅测试真实云端调用，不以离线结果冒充成功。

Windows x64 随包增加约 **50.5 MiB** 的模型及运行文件（另有许可说明）；这是解压后的资源大小，安装包压缩增量以实际构建为准。Windows 需要 10 1903 或更高版本，语音程序单独启用 UTF-8，不修改系统区域或编码设置。

开发时 `npm run dev` / `npm start` 自动准备当前平台资源；也可先运行 `npm run prepare:speech`。打包钩子按目标平台自动准备资源，支持 Windows x64、macOS arm64/x64 和 Linux x64。首次开发或构建需要联网下载，下载地址及 SHA-256 固定在 `scripts/speech-assets.json`；后续复用并校验缓存。构建电脑需要可用的 `curl` 和 `tar`。资源在 `resources/offline-tts/`，不提交二进制到 Git；安装包通过 `extraResources` 内置模型、当前平台运行库和开源许可，不重复塞入 app.asar。资源缺失会阻止打包；已安装文件丢失时，Pad 会提示重新安装完整版本。

工单逐条播放，只有完整播放结束才保存已播记录；失败、中断、切换角色或关闭播报都不会把未播完的任务记为成功。平台音频缓存有效期为 10 分钟（云端故障产生的离线备用音频仅缓存 5 秒），内存上限为 24 MiB，保存语音设置后新请求使用新配置。临时音频文件生成后即清理。更新此功能后需重启平台，并刷新安卓任务页。

运行 `npm run test:speech` 验证云端协议、流式 WAV 长度处理、密钥保存边界、故障切换、音频接口、AI 诊断、工单关闭提醒和播放状态（云端回归测试使用模拟请求，无需真实密钥）；准备资源后设置 `SPEECH_SMOKE_NATIVE=1` 可额外验证真实离线合成、中文安装路径、数字和特殊字符。`SPEECH_SMOKE_RESOURCES` 可指向打包后的 resources 目录，`SPEECH_SMOKE_OUTPUT` 可保存试听 WAV。Windows CI 同时测试开发资源和安装包资源。自动测试模拟安卓缺少语音 API 和浏览器拦截，设备实际发声仍需在现场安卓设备验证。

### 访问配置

内置服务仍监听所有网卡，但管理端生成和分享的 Pad 地址固定使用 Wi-Fi 网卡的 IPv4 地址。Windows 会优先根据系统报告的 NDIS 无线物理介质识别真实 Wi-Fi 网卡，不依赖网卡显示名称；macOS 默认识别 `en0`，Linux 默认识别常见的 `wlan`/`wlp` 网卡。

如果设备的 Wi-Fi 网卡名称不同，可用 `APP_WIFI_INTERFACE` 明确指定：

```bash
APP_WIFI_INTERFACE=en0 npm run dev
```

Windows PowerShell 示例：

```powershell
$env:APP_WIFI_INTERFACE='Wi-Fi'
npm run dev
```

Wi-Fi 网卡没有活动 IPv4 地址时，应用会在终端打印警告并把分享地址限制为 `127.0.0.1`，不会自动切换到有线或虚拟网卡；应用本身仍可在本机启动。建议在路由器中为运行软件的电脑设置 DHCP 地址保留，避免分享链接随 Wi-Fi 地址变化。
